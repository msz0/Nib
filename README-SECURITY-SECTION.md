## Security and privacy

Nib is an open-source Windows companion with optional desktop and online integrations. Notes and settings are stored locally; features such as Spotify, calendar subscriptions, lyrics, AI chat and update checks can access external services.

Clipboard history is kept in application memory when its widget is enabled. Nib can move selected files, launch apps, and integrate with Claude Code. Review these capabilities before connecting sensitive accounts or workflows.

- [Privacy policy](PRIVACY.md) — what Nib stores and which features communicate online.
- [Security policy](SECURITY.md) — how to report vulnerabilities responsibly.
- [Changelog](CHANGELOG.md) — user-visible changes between releases.

Nib has not been independently security-audited. Source availability does not by itself guarantee the safety of compiled installers.
