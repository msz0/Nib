Nib Custom Theme + Matching Tiles Patch


The Custom theme color controls are inside Theme and appear only when Custom is selected.
All Custom-theme tiles, widget cards, nav highlights, and text now adapt to the chosen notch color (including light and dark presets).
These changes do not automatically alter Dark, Light, or Night.
Run npm run dist and install the newly generated Nib-Setup.exe.
Not Windows runtime-tested.
