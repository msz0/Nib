Nib manual capture update

Capture area opens a temporary Snipping-Tool-like selection layer. Drag over the desktop and release, or press Escape to cancel. The layer closes and the selected part appears in the tool window.

The temporary selection layer covers the primary display during selection only. The screenshot editing/OCR window itself is not fullscreen. This build has not been run on Windows.

Close Nib fully before replacing files. Existing Tesseract bundling remains unchanged.
