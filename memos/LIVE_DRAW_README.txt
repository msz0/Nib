Live Draw has been restored as a transparent desktop overlay. Choose Nib > Screen tools > Draw, draw on top of your desktop, use Undo/Clear/color and Exit or Esc to close. OCR remains unchanged. Drawing is on the overlay, not permanently saved to the desktop. The overlay intercepts input while active; Exit or Alt+F4 returns to desktop. On multi-monitor setups the overlay opens on the monitor containing the cursor. Not runtime-tested on Windows.
